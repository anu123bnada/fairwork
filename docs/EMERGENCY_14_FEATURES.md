# ORYQEN: the 14 working features (28 Oct 2026)

Truth rules used here. A feature counts as **working** only if its core journey runs end to end with a real signed-in user, the real API route, real PostgreSQL under row-level security and the right permissions, and that journey has automated evidence from the **real-stack harness** (`scripts/test-local-real-workflows.mjs`: local Supabase Auth and PostgreSQL in Docker, a real Next.js server, real browser contexts, real delivered local email) or from an equivalent real-service run. Unit tests, mocked browser specs and PGlite alone are **not** counted as end-to-end. **Hosted verified** means verified on the owner's hosted Supabase and Vercel: nothing has been (no hosted change was made), so hosted is 0 for every row.

"Working" here means a usable vertical slice, **not** that the whole module in the master specification is complete. The module-level truth stays in `ORYQEN_22_MODULE_ACCEPTANCE.md`: 1 module complete (18), 20 partial, 1 blocked (19), 0 production-verified.
