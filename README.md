# ORYQEN

Pronounced **OR-i-ken**. Understand offers, clarify agreements and keep a private work record.

This is a **local, synthetic-data development build**, not a production or store release.
The application preserves the FAIRWORK trust engine and existing internal identifiers.

Start with [CONTINUE_HERE.md](CONTINUE_HERE.md), [current module audit](docs/ORYQEN_DISCOVERY.md), [verification](docs/ORYQEN_VERIFICATION.md) and [release gates](docs/ORYQEN_RELEASE_GATES.md). Brand clearance remains pending; see [research](docs/ORYQEN_BRAND_RESEARCH.md).

Local commands: `npm ci`, `npm run dev`, `npm test`, `npm run typecheck`, `npm run lint`, `npm run build`. Copy `.env.example` only when configuring a local synthetic environment; never publish secrets. Server routes require a running Next backend, including in Android.

Implemented: secure offer/question/agreement workflows, work records, corrections/withdrawals, private Passport eligibility and scoped case review. Named-recipient sharing, privacy fulfillment, authority-wide fraud handling and real deployment/device verification remain incomplete. Uploads, notifications, AI and discovery are future scope.
